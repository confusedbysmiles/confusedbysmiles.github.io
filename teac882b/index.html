What this course was

A prototyping practicum — JavaScript, APIs, and a tour of database shapes: relational, document, graph, vector. The deliverable was a working prototype and an account of building it. I built two, and they were never really separate. The first was a Student Agency Math Problem Generator: a student picks a topic, a difficulty, and a context from their own life — sports, cooking, gaming — and a model writes them a problem. The second was a tracker to document building the first: formative memories with technology and mathematics, then a running log of decisions, obstacles, and the questions that surfaced while the generator came together.

The tracker outgrew the assignment. It runs on a graph database now — Neo4j Aura, reached through a Cloudflare Worker because the Neo4j driver will not run inside one, which took a week of wrong endpoints and a credentials file that listed the instance id as the database name to discover. It has a live graph viewer. It has an authentication layer. It is the instrument behind this portfolio’s gated artifacts.

The deck names the biggest risk to the tracker in one line: might not use it consistently. That line was right.

Dissertation corpus

Through line

The build prompt for the tracker is dated 12 February 2026. It describes the dissertation as a study of “student agency in math education, specifically for students retaking Algebra 1.” Four days later, on 16 February, the purpose statement written for EDPS 936 reframed the dissertation as a mixed methods autoethnography with a single participant — me. The instrument was specified before the study it now carries existed, for a study that no longer does. The prompt has not been updated. It does not need to be; it is data now.

The same prompt says, in its thirteenth line: “This tracker IS my dissertation data — it’s ‘reflection through making.’” That phrase is one of the six themes in the EDPS 936 joint display, written weeks afterward. I had the name for the theme before I had the study it belonged to.

And the deck’s design for the tracker — “research journal meets development log, with AI helping spot patterns between past experiences and current decisions”; a reflection prompt that asks “You mentioned struggling with rigid math curricula as a student. How is that shaping your design choices here?” — is the use of generative technology I later declared to my committee before beginning comprehensive exams: retrieval and connection-finding across my own record, not generation. The declaration describes a tool. The tool was designed first.
